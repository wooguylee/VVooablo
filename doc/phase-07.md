# Phase 7 — 아이템/접사 롤링 + 드롭 + 인벤토리/장비 + 스탯 재계산 + 툴팁

작업일: 2026-08-31
상태: **완료** (build/test/lint/브라우저 스모크 통과, 91 tests)

## 구현 산출물

### data/
- `itemTypes.ts` — 등급(일반/마법/희귀/전설), 장비 슬롯 8종, ModKey, ItemInstance, 등급별 색상/접사 개수.
- `items.ts` — 아이템 베이스 테이블(무기/방어구/투구/장갑/신발/반지/목걸이), 슬롯별 그리드 크기.
- `affixes.ts` — prefix/suffix 접사 테이블, 아이템 레벨 기반 tier(값 범위), 슬롯 제약.

### systems/items/
- `generateItem.ts` — 아이템 롤링(등급→베이스→접사 tier 선택→값 롤링), UID 관리. 전부 시드 RNG 결정성.
- `equipment.ts` — Equipment/Inventory 컴포넌트 + **스탯 재계산 파이프라인**(장비 modifier 합산 → 코어/파생 스탯, 무기 피해 = (기본+무기+평타)×(1+증가%)).
- `equipSystem.ts` — 장착/해제(반지 슬롯 자동 배정), 라이브 엔티티 스탯 반영(체력 비율 유지).
- `dropSystem.ts` — 사망 시 드롭 롤링(확률/보너스롤/골드).

### entities/
- `playerProfile.ts` — 층 전환에도 유지되는 영속 프로필(레벨/코어/장비/인벤/골드/포인트).
- `createPlayer.ts` — 프로필 주입 + 재계산 스탯 적용.

### render/
- `GroundItems.ts` — 지면 아이템/골드 표시 + 근접 자동 획득.

### ui/
- `itemTooltip.ts` — modifier → 한국어 문구 툴팁 HTML.
- `InventoryPanel.ts` — I 토글, 장비 슬롯 + 가방 그리드, 클릭 장착/해제, 호버 툴팁, 골드.

### core/
- `Game.ts` — 영속 프로필 보관, 적/엘리트/보스 차등 드롭, 지면 아이템 픽업, 장착/해제 연동.

## 설계 메모
- **재현성**: 아이템/접사/드롭 전부 층 RNG 파생. 같은 시드 → 같은 전리품.
- **스탯 파이프라인**: baseCore(레벨/특성) + 장비 → recalcStats 단일 경로. 장착 시 즉시 재계산·체력 비율 보존.
- **영속성**: 플레이어 엔티티는 층마다 재생성되지만 PlayerProfile은 Game이 유지 → 인벤토리/장비 보존.
- **드롭 차등**: 일반 18%, 엘리트 60%+보너스1, 보스 100%+보너스3, 아이템레벨은 층 몬스터레벨 기반.
